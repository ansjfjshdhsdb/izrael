# ISRP · UKR Israel

Портал игрового сервера с правилами, криминальным кодексом, полномочиями служб и общим реестром лицензий. Публичный поиск работает по нику, ID записи и номеру лицензии. Вкладка «Адвокаты» ищет только в адвокатуре.

## Запуск с панелью управления

Установите Python 3.10 или новее. В каталоге проекта выполните команды в виртуальном окружении Python. Пароль администратора вводится в терминале при настройке.

```sh
python -m pip install -r requirements.txt
python server.py set-password
python server.py serve --local-http
```

Откройте `http://localhost:8000`. В разделе «Управление» войдите с созданным паролем. Кнопка «Добавить игрока» открывает форму лицензии. Укажите организацию, роль, игровой ник, номер и даты документа. После сохранения ссылка «Проверить запись» открывает публичную карточку. Для редактирования или отзыва откройте строку в панели и сохраните изменения. Дубликаты номеров лицензий отклоняются. Статус учитывает даты выдачи и окончания по UTC.

## Развёртывание и хранение

На **israelrp.online** сайт и маршруты `/api/*` обслуживает Cloudflare Worker **izrael**. Сборка публикует клиент из `dist`. При развёртывании Wrangler подключает D1 с именем привязки **DB**. Worker создаёт недостающие таблицы при первом обращении, сохраняя существующие лицензии. Реестр новой базы пуст.

Для входа на рабочем домене откройте **Cloudflare → Workers & Pages → izrael → Settings → Variables and Secrets**. Добавьте секрет **ADMIN_PASSWORD** со своим паролем (от 12 до 256 символов), сохраните его и нажмите **Deploy**. Войдите с этим паролем на <https://israelrp.online/#admin>. При смене секрета существующие сеансы завершаются.

Запустите `python server.py serve` за HTTPS-прокси с постоянным диском. Сервер Waitress по умолчанию слушает `127.0.0.1:8000`. Хост и порт настраиваются флагами `--host` и `--port`. Для этого режима cookie входа передаются только через HTTPS. Параметр `--local-http` предназначен для локальной разработки.

По умолчанию SQLite хранится в `~/.local/share/isrp/registry.sqlite3`. Переменная окружения `ISRP_DB` или параметр `--db` задаёт другой путь. Используйте одну и ту же базу для настройки пароля и запуска сервера. Базу следует хранить вне каталога публикации и включать в резервное копирование. Команда `set-password` меняет пароль и завершает существующие сеансы. Вход действует восемь часов.

В закрытом превью Devin владелец может задать первый пароль через экран «Управление». Режим `--private-setup` разрешает первому посетителю создать пароль, поэтому он предназначен исключительно для экземпляра, уже закрытого внешней авторизацией. Для публичного хостинга используйте настройку через терминал.

На статическом хостинге можно разместить `index.html`, `app.js`, `admin.js`, обе готовые таблицы стилей `styles.css` и `portal.css`, каталоги `media` и `data`. В этом режиме работают документы и поиск по опубликованному снимку JSON. Сохранение общих записей требует запуска сервера.

## Данные

- В `data/documents.json` сохранены 21 раздел правил (107 пунктов), 6 разделов криминального кодекса (35 пунктов) и полномочия 7 служб. Пункт 12.4 и разорванный при вставке пункт 15.2 ранее приведены к читаемому виду. В пунктах 21.6–21.8 исправлены явные опечатки.
- В исходном ТЗ правило 8.4 устанавливает за перестрелку в зелёной зоне бан на 5 дней, а пункт 6.6 кодекса указывает перманентную блокировку за стрельбу в Green Zone. Обе формулировки сохранены для решения владельцем проекта.
- В `data/licenses.json` заданы организации, допустимые роли и три демонстрационные лицензии. Записи импортируются один раз при создании базы. Демо-записи сохраняют пометку даже после редактирования. Реальные лицензии администратора видны через публичную проверку, а их количество отражается в статистике.
- Обложка использует три предоставленных игровых снимка. Шрифты хранятся вместе с сайтом, лицензии приложены в `media`.
