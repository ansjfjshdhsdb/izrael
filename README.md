# ISRP · UKR Israel

Игровой правовой портал с документами сервера, проверкой лицензий и панелью управления. Публичная проверка ищет по нику, ID или номеру лицензии. Фильтр «Адвокатура» показывает записи адвокатов.

## Локальный запуск

Понадобятся Node.js 22 или 24 и npm. В корне проекта создайте файл `.dev.vars` и задайте в нём `ADMIN_PASSWORD` с собственным длинным случайным значением. Затем выполните:

```sh
npm ci
npm run preview
```

Откройте адрес из вывода Wrangler (обычно http://localhost:8788). Команда соберёт сайт, подготовит локальную базу D1 и запустит Pages Functions. Записи сохраняются между перезапусками в `.wrangler/state`. Во время разработки после изменения клиентских файлов обновите сборку командой `npm run build`.

## Панель управления

1. Откройте «Управление» и введите пароль администратора.
2. Нажмите «Добавить игрока». Укажите ник, ID, фракцию, роль, номер лицензии и обе даты. Для адвоката выберите фракцию «Адвокатура».
3. Откройте «Проверка игрока» и введите ник, ID или лицензию. Результат содержит фракцию, роль, срок и статус. Для проверки интерфейса доступен ник `Demo_Judge`.
4. Чтобы отозвать лицензию, нажмите кнопку редактирования в строке игрока и выберите «Аннулирована». Срок действия проверяется и по датам.
5. На вкладке «Документы» выберите документ, раздел и пункт. Сохранённый текст публикуется в соответствующем разделе портала.

Запись в базу требует серверной проверки пароля. Интерфейс хранит пароль в памяти вкладки до выхода или перезагрузки. ID и номера лицензий уникальны. Если два администратора редактируют одну запись, при сохранении устаревшей версии сервер предложит обновить страницу.

## Публикация на Cloudflare Pages

1. Создайте базу **D1** в аккаунте Cloudflare. Выполните в ней SQL из `migrations/001_registry.sql`. Через авторизованный Wrangler это можно сделать командой `npx wrangler d1 execute ИМЯ_БАЗЫ --remote --file migrations/001_registry.sql`.
2. В настройках проекта Pages привяжите D1 к переменной **DB**. Добавьте зашифрованный секрет **ADMIN_PASSWORD** с паролем администратора. Для preview-окружения используйте отдельную базу и пароль.
3. Для сборки задайте `npm run build`, корневой каталог проекта и выходной каталог `dist`. Pages соберёт API из корневой папки `functions`. Запустите новый деплой после настройки привязок.

Сборка `dist` также работает на обычном статическом хостинге в режиме чтения. Тогда проверка использует `data/licenses.json`. Общие изменения через панель доступны при подключении серверной части и базы.

## Данные проекта

- `data/documents.json` содержит 21 раздел правил (107 пунктов), 6 разделов криминального кодекса (35 пунктов) и полномочия 7 служб. Текст перенесён из предоставленного ТЗ. Пункт 12.4 и разорванный при вставке пункт 15.2 приведены к читаемому виду. В пунктах 21.6–21.8 исправлены явные опечатки и расставлены пробелы.
- `data/licenses.json` содержит справочник фракций и ролей и три демонстрационные записи. Те же записи включены в начальную миграцию D1. У демозаписей сохраняется пометка «Демо» при редактировании.
- На сервере лицензии и изменения пунктов хранятся в D1. Правки текста привязаны к позиции пункта в исходном документе. При перестановке разделов или пунктов перенесите соответствующие ключи в таблице `document_edits`.

В исходном ТЗ есть противоречие: правило 8.4 устанавливает за перестрелку в зелёной зоне бан на 5 дней, а пункт 6.6 кодекса указывает перманентную блокировку за стрельбу в Green Zone. На сайте обе формулировки сохранены.
