# ISRP · UKR Israel

Статический портал с правилами сервера, криминальным кодексом, полномочиями служб и проверкой лицензий сотрудников.

## Запуск

Для локального просмотра:

```powershell
npm install
npm run preview
```

Откройте `http://localhost:8000`. Сайт использует `fetch` для JSON, поэтому при открытии `index.html` через `file://` данные могут не загрузиться. Можно использовать и любой другой локальный статический сервер.

Для публикации достаточно разместить `index.html`, `app.js`, `styles.css` и папку `data` на статическом хостинге. Сборка данных не требуется.

## Данные

- `data/documents.json` содержит 21 раздел правил (107 пунктов), 6 разделов криминального кодекса (35 пунктов) и полномочия 7 служб. Текст перенесён из предоставленного ТЗ. Пункт 12.4 и разорванный при вставке пункт 15.2 приведены к читаемому виду; в пунктах 21.6–21.8 исправлены явные опечатки и расставлены пробелы.
- `data/licenses.json` содержит список фракций, ролей и записей лицензий. В комплекте есть только три **демонстрационные** записи. Они не подтверждают полномочия реальных игроков. Замените `records` проверенными данными проекта перед использованием реестра.

Каждая запись лицензии имеет поля `id`, `nickname`, `faction`, `role`, `license`, `issuedAt`, `expiresAt`, `status` и `demo`. Даты задаются в формате `YYYY-MM-DD`. Для реальных записей установите `demo: false`; допустимые статусы: `active`, `expired`, `revoked`. Значение `faction` должно совпадать с `id` фракции из массива `factions`, а `role` — с одной из её ролей.

В исходном ТЗ есть противоречие: правило 8.4 устанавливает за перестрелку в зелёной зоне бан на 5 дней, а пункт 6.6 кодекса указывает перманентную блокировку за стрельбу в Green Zone. На сайте обе формулировки сохранены; перед публикацией правил владельцу проекта стоит выбрать единую санкцию.

Этот сайт читает открытый JSON-файл. Для закрытого редактирования реестра, авторизации сотрудников или защиты от подмены данных нужен серверный компонент.
